# 在宅医療・訪問契約

対象候補は [ドメイン候補一覧](../domain-candidates.md) を参照。

外来1回完結の処方・調剤とは異なる長期契約ライフサイクルとして、医師の訪問指示・患者同意・薬学的管理指導計画に基づく在宅療養契約、医療保険と介護保険（居宅療養管理指導）の切り分け、単一建物診療患者人数・16km制限・回数上限、および多職種連携を扱う。

- [在宅医療・訪問薬剤管理](home-care.md): 在宅療養契約のライフサイクル（`契約準備` → `ACTIVE` → `TERMINATED`）、介護保険優先原則、訪問時の処方箋原本受領・同一確認義務、単一建物・回数上限、多職種共同指導・在宅協力薬局連携
- [インタラクティブ図解 (HTML)](diagram.html): 在宅療養契約の状態遷移、医療保険/介護保険の分岐、単一建物人数・16km・回数上限、基幹/協力薬局連携の図解
