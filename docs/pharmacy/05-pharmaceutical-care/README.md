# 服薬指導・薬歴・継続ケア

対象候補は [ドメイン候補一覧](../domain-candidates.md) を参照。

患者配下の受付・相談・フォローアップ等のイベントを軸に、服薬指導・薬剤交付、SOAP・法定確認事項を含む薬歴記載（確定・追記訂正履歴・頭書き連動）、調剤後のフォローアップ、および医療安全（ヒヤリハット・インシデント）を扱う。

- [受付・相談・フォローアップのイベント](care-event.md): 内部受付共有・外部NSIPS取込によるイベント先行作成、薬歴確定によるイベント完了と不足事項の注意喚起、イベント間の関連
- [服薬指導・交付](medication-counseling.md): 対面/オンライン/訪問指導、お薬手帳（JAHIS出力制約含）、かかりつけ、特定指導、薬剤情報提供文書・交付記録
- [薬歴記載](medication-history.md): SOAP・法定確認事項（残薬なし明記必須等）、下書き・保険薬剤師確定（イベント完了・不足事項注意喚起）・複数者記載時の確定薬歴への追記・二本線抹消相当の訂正履歴、患者頭書きへの追記連動
- [フォローアップ](follow-up.md): 元の薬歴と関連づける独立した実施記録、双方向確認要件、麻薬継続確認、同一テナント内他店舗への引継ぎ
- [品質・インシデント](quality.md): 薬局ヒヤリ・ハット事例収集・分析事業ベースの起票・調査・是正・効果確認（発生店舗の開設法人が管理）
- [インタラクティブ図解 (HTML)](diagram.html): イベント・薬歴確定（＝イベント完了・不足事項注意喚起）・複数者追記・継続的留意点引継ぎ・加算別構造化根拠・フォローアップ・品質管理の図解

関連: [薬局ドメイン全体関係図 (HTML)](../diagram.html)、[患者・受給資格](../03-patient-coverage/README.md)、[処方・調剤](../04-prescription-dispensing/README.md)、[在宅医療](../06-home-care/README.md)、[業務フロー](../workflow.md)。
