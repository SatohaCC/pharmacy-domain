# 在庫・物販

[ドメイン一覧](../domain-candidates.md) の調達・在庫（`inventory`）および商品・物販（`retail`）の仕様を定義する。要指導医薬品・一般用医薬品（OTC）に限らず、衛生用品・健康食品・日用品など薬局で販売する商品全般を対象とし、保険調剤の算定・請求から独立したコンテキストとして構成する。

- [調達・在庫管理](inventory.md): 発注・入庫・ロット/使用期限管理、調剤・物販確定に伴う払出と訂正時の逆仕訳（戻入）、同一法人店舗間移動・他薬局分譲（別紙様式4-1・2年保存連動）、廃棄、麻薬・向精神薬・覚醒剤原料・毒薬劇薬の受払帳簿
- [商品・物販管理](retail.md): 要指導・第1〜3類OTC・医薬部外品・衛生用品・健康食品・日用品の商品分類、販売資格者ガード（薬剤師・登録販売者）、濫用等のおそれのある医薬品の法定確認ガード、セルフメディケーション税制区分、窓口会計・OTC相談イベント連携
- [インタラクティブ図解 (HTML)](diagram.html): 在庫受払ライフサイクル、規制薬品帳簿・分譲連携、OTCリスク区分別販売ガードの図解
