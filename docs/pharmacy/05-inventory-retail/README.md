# 在庫・物販

[ドメイン一覧](../domain-candidates.md) の調達・在庫、商品・物販を整理する。OTCに限らず衛生用品・健康食品・日用品など、薬局で販売する商品全般を対象とする。算定・会計・請求から独立した業務分類とする。

| 候補 | 主な対象 | 他領域との関係 |
| --- | --- | --- |
| 調達・在庫 | 発注、入庫、ロット・期限、移動、払出、廃棄 | 調剤・販売の実績と物品移動を対応づける |
| 商品・物販 | 商品情報、販売・取消、商品区分に応じた確認・情報提供・記録 | 医薬品情報と対応づけ、在庫・会計に販売や取消の結果を渡す |

個別文書は未作成。医薬品固有のルールと商品共通のルールの分離、外部システムとの分担、訂正・取消時の在庫・会計への反映は今後検討する。
