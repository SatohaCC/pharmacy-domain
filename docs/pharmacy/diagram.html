薬局業務の6フェーズと8コンテキストの対応

Phase 1: 開設・体制・行政対応01 / 02

開設許可・保険指定・麻薬免許更新、管理薬剤師専任配置（経験5年/週32h/在籍1年）、施設基準届出、ウェブサイト掲載、安全管理GL第7.0版（二要素認証・共有ID禁止・NTP監査ログ・年次監査・教育訓練）。

Phase 2: 受付・資格・調剤前確認03 / 04

受入禁止処方箋（二枚処方箋等）ブロック、オン資確認、FAX電送処方箋の原本受領突合、保険薬剤師専権の取りそろえ前確認、薬学的監査、疑義照会ゲート（法24条）。

Phase 3: 調剤・変更・分割・鑑査04 / 08

自家製剤（収載品非存在・工程記録）・計量混合・一包化、含量/類似別剤形変更の4要件、供給不安分譲（別紙4-1・2年保存）、分割/リフィル記入、保険薬剤師本人の署名。

Phase 4: 指導・交付・薬歴/調剤録確定04 / 05

薬剤情報提供文書（後発品備蓄名・価格比較明記）、手帳理由記載、残薬なし明記、前回留意点回収（CarryOverPrecaution）、加算別構造化根拠（FeeJustification）、薬歴確定＝イベント完了。

Phase 5: フォロー・多職種連携・在宅05 / 06

双方向フォローアップ（元薬歴と別記録で関連づけ・他店舗引継可・麻薬継続確認）、服薬情報等提供料1（医療機関求め必須）、在宅契約・介護優先・単一建物判定。

Phase 6: 算定・会計・レセ電請求・審査07

無状態点数計算、TK 選択式コメント10類型、窓口会計（減免禁止・0円明細書無償交付）、請求前3者突合（PreClaimReconciliation）、16レコード出力、返戻再請求、増減通知是正。
