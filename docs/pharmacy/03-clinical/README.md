# 患者・臨床・ケア

対象候補は [ドメイン一覧](../domain-candidates.md) を参照。

入口は患者とする。登録済み患者の配下に受付・相談・フォローアップ等のイベントを作成し、そのイベントに薬歴記載を紐づける。患者なしのイベントは作成しない。

- [処方箋と処方内容](prescription.md)
- [患者](patient.md): 全店舗共通の患者と、レセコン共通患者番号の対応
- [受付・相談・フォローアップのイベント](care-event.md): 内部の受付情報共有・外部NSIPS取込によるイベント作成、後からの記録、イベント間の関連
- [薬歴記載](medication-history.md): 下書き、確定、追記・訂正履歴
- [フォローアップ](follow-up.md): 元の薬歴と関連づける独立した実施記録
- [品質・インシデント](quality.md): ヒヤリハット収集事業ベースの報告・調査・改善・確認
- [業務フロー](workflow.md): レセコン入力 → 服薬指導 → 薬歴記載 → フォローアップ

保険・公費等、レセコン入力・連携、処方監査・疑義照会、調剤・鑑査、服薬指導・交付、在宅の個別文書は未作成。

一体型内部は直接情報を共有し、NSIPSは外部連携用とする。他社の分包機等への連携も含め、[連携境界](../external-integration.md) を参照。
