# 処方・調剤

対象候補は [ドメイン候補一覧](../domain-candidates.md) を参照。

処方箋の受付・取込から、取りそろえ前確認・処方監査・疑義照会、具体的製品の選択・調剤手技・最終鑑査・調剤録作成までの調剤室・レセコン中核業務を扱う。

- [レセコン入力・連携](reception-entry.md): 受付入口、紙/QR/電子処方箋/NSIPS取込、受入禁止処方箋のブロック、使用期間確認、同時受付・分割/リフィル識別
- [処方箋と処方内容](prescription.md): 紙・電子処方箋の原記載保全、変更指示との区別、NSIPS再受信上書き方針
- [処方監査・疑義照会](prescription-review.md): 保険薬剤師による取りそろえ前確認、形式・薬学的監査、疑義照会完了ゲート（薬剤師法第24条）、単一ソース疑義照会ID、残薬調整・薬学的有害事象等防止の根拠
- [調剤・鑑査](dispensing.md): 保険調剤と自費等の調剤録分離、後発品・含量規格/類似別剤形変更の4要件、レセ電剤形別用量（`SH`/`CZ`/`IY`/`TO`）、調剤手技・規制薬品・供給不安対応記録、最終鑑査・調剤録訂正履歴
- [インタラクティブ図解 (HTML)](diagram.html): 受付・処方監査・単一ソース疑義照会・変更調剤4要件・調剤録とレセ電レコードの関係図

関連: [薬局ドメイン全体関係図 (HTML)](../diagram.html)、[患者・受給資格](../03-patient-coverage/README.md)、[服薬指導・薬歴・継続ケア](../05-pharmaceutical-care/README.md)、[算定・会計・請求](../07-reimbursement-billing/README.md)、[業務フロー](../workflow.md)。
