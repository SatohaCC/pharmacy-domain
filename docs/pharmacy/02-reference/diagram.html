薬価経過措置満了日 04 調剤 / 07 算定・請求 調剤実施日時点で経過措置期間が満了している医薬品の選択・保険請求をブロックする。
長期収載品選定療養区分 04 調剤 / 05 指導 / 07 算定・会計 医療上の必要性か患者希望かを区別し、特別の料金（選定療養費）の算出および摘要欄（TK）理由抽出に用いる。
ハイリスク薬・RMP資材区分 05 服薬指導・薬歴記載 特定薬剤管理指導加算1（イ/ロ）および3（イ：RMP資材説明交付）の構造化算定根拠（FeeJustification）と連動する。
処方医の保険医フラグ・麻薬施用者番号 04 受付・処方監査 非保険医の処方箋による保険調剤をブロックし、麻薬処方時の麻薬施用者免許番号を検証する。
介護施設の施設種別 05 服薬指導 / 06 在宅 / 07 算定 特別養護老人ホーム（服薬管理指導料3・施設連携加算）と自宅・有料老人ホーム等（訪問薬剤管理指導料／居宅療養管理指導費）の算定区分を分岐させる。
