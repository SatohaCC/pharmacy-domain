# 共通の詳細論点

法人・店舗・許認可・データ承継にまたがる横断仕様を定義する。基本構造は [法人と法人間の関係](corporate.md) と [店舗](store.md)、用語は [用語・履歴と領域間の受け渡し](organization-contracts.md#用語)、テナント分離と認可は [テナント・アクセス管理](tenant-access.md) を参照。

## 管理する概念と横断設計

| 概念 | ドメイン上の役割 | 設計上の不変条件 |
| --- | --- | --- |
| 法人 (`Corporation` / `Operator`) | 開設主体となる法人（区分：`法人` / `個人`）。持株会社や個人開設者も含む | 1法人＝1テナント。実務の運営担当との分離は想定しない |
| 法人間関係 (`CorporateRelation`) | `親子（支配）`（最大1親）・`関連会社`・`FC・VC契約` と適用期間 | 方向、根拠メモ（議決権比率・役員兼任・実質支配・契約等）、確認状態を保持。個人区分でも役員兼任・実質支配等がある場合は登録可 |
| 屋号・ブランド (`Brand`) | 店舗が使用する名称・ブランド | 法人と1対1にせず、店舗への適用期間を持つ |
| 薬局店舗 (`PharmacyStore`) | 業務上継続して扱う店舗単位 | 物理拠点そのものとは区別。移転・譲渡時の同一店舗ID維持有無は運用判断で選択可 |
| 物理拠点 (`StoreLocation`) | 住所・区画・緯度経度・プライバシー配慮設備等の場所 | 移転時は別拠点を登録し利用期間を切り替える。同じ場所への再出店を自動的におなじ店舗にしない |
| 店舗と開設者の関係 (`StoreOperatorAssignment`) | 店舗の開設主体（法人）と期間 | 半開区間 `[valid_from, valid_to)` で当時の開設主体を参照できる履歴を保持 |
| 許可 (`FacilityLicense`) | 許可種別（薬局開設許可・麻薬小売業免許・店舗販売業許可等）、名義人、発行者（許可権者）、対象店舗、番号、有効期間・有効期限 | 1店舗に複数紐づけ可能。麻薬小売業免許の期限切れ・未登録時は麻薬調剤・摘要記載をブロック |
| 保険指定 (`InsuranceDesignation`) | 指定を受けた開設者、対象店舗、都道府県コード(2桁)・点数表区分(1桁)・機関コード(7桁)、指定日、適用期間、`predecessor_id`（承継元指定ID） | 旧指定との承継系譜を保持。系譜自体は実績合算や薬歴閲覧許可の根拠とはしない |
| データ承継 (`DataSuccession`) | 対象記録集合、提供元・承継先、根拠、利用目的、承認、切替結果 | 指定の承継系譜やテナント所属から独立して管理する |

## 店舗の同一性と継続性

移転により `StoreLocationId` は切り替わる。`PharmacyStoreId` を維持するか新規発行するかは運用判断で選択でき、事業譲渡時も同様とする。許可・保険指定・コードの維持や再取得はこの判断とは独立して記録する。

## 期間と履歴の原則

- **半開区間**: 有効期間はすべて `[valid_from, valid_to)` に統一し、終了未定は `valid_to` なしとする。切替日 `D` では旧関係の終了と新関係の開始をともに `D` とする。
- **日単位と時刻単位の区別**: 組織所属や指定期間等の日単位の事実には日付を用い、勤務実績等の時刻が必要な事実にはタイムゾーン付き日時を用いる。
- **バイテンポラル追跡**: 業務上有効になった時点と、システムに登録・訂正した時点を区別し、遡及指定や後日訂正でも当時の登録状態を追跡可能にする。

## 報酬上の同一グループ判定 (`GroupAssessment`)

法人間関係（`CorporateRelation`：`親子（支配）` / `関連会社` / `FC・VC契約`）を材料とし、特掲診療料の施設基準等（同一開設者、最終親会社等、子会社等、関連会社等、役員兼任・実質支配、FC・VC契約）に沿って評価する。判定結果の正本は [施設基準・届出](facility-compliance.md) で保持し、算定領域へ渡す。

### 判定手順

1. **支配関係の上向き探索**: 対象法人から `親子（支配）` 関係を上向きにたどり（循環検出あり）、最終親会社等の起点候補を導出する。
2. **関連・FC/VC関係の起点導出**: 対象が関連会社・FC/VC加盟側の場合、その関連元・契約本部からも起点候補を得る（関係の向きと役割を明示し、関連先同士を無制限に再帰結合しない）。
3. **グループ範囲の展開**: 起点候補ごとに、適用制度版が定める子会社等・関連会社等・FC/VC先の範囲を時点 `as_of` で評価する。
4. **確定と検証**: 対象法人が含まれる同一グループ開設者集合を導出する。複数候補や根拠不足・矛盾がある場合は「要確認」状態とし、確認完了後に自動算定へ適用する。

## 管理薬剤師等の就任との接続

同一施設で同じ薬剤師が管理薬剤師を継続したまま薬局開設許可の世代（更新・切替）だけが変わった場合、実際の兼務が生じたものとは判定しない。一方、同一時点における異なる複数店舗での管理薬剤師就任の期間重複は、薬機法第7条・28条の専任義務違反としてブロックする。

## M&A・組織変更ケース別の処理仕様

| ケース | ドメイン上の維持・変更処理 | 確認・統制ルール |
| --- | --- | --- |
| 法人Aが店舗X・Yを開設 | 法人、店舗、物理拠点、開設者関係、許可・保険指定を登録 | すべての臨床・請求記録が実施日時点の主体・指定を参照する |
| 法人Bが法人Aを株式取得（Aが存続） | Aの法人ID・テナント・店舗ID・許可・保険指定を維持。`CorporateRelation` を更新 | グループ判定日と算定反映時期を管理し、親子関係を理由にBへAの薬歴閲覧を許可しない |
| 法人Aから法人Bへ店舗Xを事業譲渡 | 店舗継続判断を記録し開設者関係を切替。新許可・新保険指定（`predecessor_id` 保持）を登録 | Xの承継対象記録・利用目的・患者同意・権限を個別承認。Yの記録は承継対象外とする |
| 法人Aが法人Bへ吸収合併 | Aの存続状態を `合併消滅` として履歴保持し、開設者関係をBへ切替 | 許可・指定手続、返戻対応、保存責任、閲覧権限を各領域で記録（包括承継＝全職員への一律閲覧許可としない） |

## データ承継と閲覧権限の不変条件

- **グループ所属と閲覧権限の分離**: 株式取得や同一グループ所属だけでは、親会社・兄弟会社への薬歴・調剤録の閲覧を一切許可しない。
- **店舗単位の部分承継**: 店舗Xの事業のみを承継した場合、同一法人の店舗Yの記録は承継スコープに含めない。旧法人A側の既存アクセスは、法定保存や未完了請求・返戻対応の必要性に基づき承認された範囲のみ維持する。
- **譲渡前実績の遡及修正禁止**: 事業譲渡前のレセプト・調剤実績は譲渡元（旧法人）の請求・調剤責任に属するため、譲渡先（新法人）側からの遡及変更・修正請求は禁止（スナップショット参照のみ）とする。
- **薬歴承継時の履歴保持**: 薬歴の承継は法令および患者同意に基づき行い、引き継いだ場合も当時の記載者・責任法人の履歴を不変に保持する。
- **調剤実施日時点の4点セット復元**: 特定共同指導およびレセプト電算出力（`CZ`/`KI`）に備え、**調剤実施日時点における「開設者・管理薬剤師・保険薬局コード・届出施設基準」をセットで復元・適用できること**を全コンテキスト共通の横断要件とする。

## 法定保存と訂正ポリシー

| 記録種別 | 保存・管理要件 |
| --- | --- |
| 調剤録 | 完結の日から3年間（生活保護法等は5年間）、保険調剤と自費等を分離し追記型訂正履歴で保持 |
| 調剤済み処方箋・電子処方箋関連記録 | 完結の日から3年間（生活保護法等は5年間）、保険薬剤師署名・記入事項とともに保持 |
| 薬歴・薬学的管理記録 | **最終記入日から起算して**3年間（生活保護法等は5年間）を下回らず、同一患者の全記録を直ちに参照可能に保持 |
| 供給不安対応記録（別紙様式4-1/4-2） | 対応日から2年間保持 |
| レセプト・会計・債権記録 | 請求・税務・返戻再請求の根拠として提出時スナップショットと承継後対応主体を保持 |
| 移行・アクセス監査記録 | 誰がいつ何を閲覧・変更・移行したかを原則物理削除不可として保持 |
