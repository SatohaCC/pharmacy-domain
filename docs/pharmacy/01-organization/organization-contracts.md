# 用語・履歴と領域間の受け渡し

状態: 相談用のモデル案。API・イベント方式・共通型の配置は確定しない。

## 用語

組織・基盤の文書では、以下の用語を使う。定義はモデル案であり、制度上の定義を置き換えるものではない。

| 用語 | 意味の案 | 区別すること |
| --- | --- | --- |
| 法人 | 薬局の開設・管理の基本単位（区分：`法人` / `個人`）。個人開設者や店舗を開設しない持株会社等もモデル上は法人として統一的に扱う | 個人区分では法人番号や親子関係を持たない |
| 企業グループ | 複数法人のまとまりを説明する呼称。独立したグループID・所属・階層は基本モデルに設けない | 報酬上の同一グループの判定結果とは別 |
| 企業間関係 | 法人間の `親子（支配）`（最大1親）・`関連会社`・`FC・VC契約` と期間・根拠メモを管理する | 報酬上の同一グループ判定に関わらない業務提携は対象外。関係があっても別テナントであり、認可とは別 |
| 開設者 | 薬局の開設主体となる法人（区分：`法人` / `個人`） | 店舗との開設関係は期間で管理する（運営担当の分離は想定しない） |
| 店舗 | 業務上継続して扱う薬局の単位（併設の店舗販売業許可等も紐づけ可） | 物理拠点、許可、保険指定とは別に識別する |
| 物理拠点 | 住所・区画等の場所 | 移転時は別の拠点として登録する |
| 報酬上の同一グループ | 制度版・基準日・対象期間に基づく判定結果 | 親子関係そのものとは別の評価結果 |
| 管理主体 | 品質の報告案件を管理する店舗の開設者（法人） | 親法人へ自動委任しない。詳細は [品質・インシデント](../03-clinical/quality.md) |
| スタッフ | テナント内で業務に従事する人物（派遣・業務委託も自法人との契約区分で表現） | ログイン主体（アカウント）と1対1だが概念として区別 |
| テナント | 法人ごとのデータ分離境界。1法人＝1テナント | 企業グループはテナントではない |
| アカウント | システムにログインする主体（テナントごとに別。スタッフと必ず1対1） | 配属と権限付与は完全に別操作 |

## 用語と情報の所有先

| 情報 | 正本を持つ領域の案 | 主な参照先 |
| --- | --- | --- |
| 法人（法人/個人区分）・法人間関係（親子/関連会社/FC） | 法人（企業） | 店舗、施設基準（報酬グループ判定）、アクセス管理 |
| 店舗・拠点・営業日時・連絡先・開設者関係・許可・指定 | 店舗 | 処方箋、調剤、請求、施設基準、算定 |
| 人物・所属契約・配属・資格・勤務・就任 | スタッフ | 調剤等の実施者、施設基準 |
| 基準の評価・届出・適用情報・報酬上のグループ判定 (`GroupAssessment`) | 施設基準 | 算定、店舗運営 |
| 報告・調査・改善 | 品質 | 店舗（起票・実施結果の報告）、法人（案件の管理）、調剤等の業務記録 |
| 法人の利用設定・アカウント・権限・監査・データ移行 | テナント・アクセス管理 | 全領域の利用認可 |

## 共通の履歴の考え方

- 業務上の有効期間は `[開始, 終了)`。日付で分かる事実には日付を使う。
- 実際の発生・効力日と、入力・訂正日時を区別する。根拠が未確認なら状態を明記する。
- 関係の終了は参照先の削除ではない。過去記録が指す主体とその時点の版を保持する。
- 予定と確定事実、申請と適用、所属と権限を区別する。
- 保存期間・訂正・削除の条件は記録種別ごとに確認する。

## 領域をまたぐ変更の確認例

| 変更 | 確認する領域と内容 |
| --- | --- |
| 企業の買収 | 企業間関係を更新し、報酬のグループ判定を再確認。店舗・権限・テナントは自動変更しない |
| 店舗譲渡 | 店舗の開設者関係、企業の承継対応、スタッフの所属・配属、施設基準、データ移行・認可を個別確認 |
| スタッフ異動 | 配属・勤務予定を変更し、就任、施設基準、権限への影響を確認 |
| 店舗閉店 | 営業状態と予定を更新し、届出、権限、請求継続、保存・参照の扱いを確認 |

組織変更の独立した案件・進捗管理は設けない。法人、親子関係、店舗の開設者、スタッフの所属・配属等が、それぞれ変更前後・有効期間・変更者・記録日時・根拠を履歴として持つ。必要な参照先は個々の履歴に保持する。一つの変更で全領域が即時に確定するとは仮定しない。

## 相談時に確認すること

1. A社がX・Yを運営し、PがXからYへ応援するとき、勤務とアクセスを別々に説明できるか。
2. Xの事業譲渡後も、譲渡前の実施者・開設者・指定を参照できるか。
3. 届出後の実績訂正で、提出済み資料を失わず再評価できるか。
4. 別法人を別テナントとして分離し、同じ法人内でも別店舗への閲覧を所属だけで許可しないか。
5. 未確認の情報を制度上の適合・算定可能という確定結果に変えていないか。
