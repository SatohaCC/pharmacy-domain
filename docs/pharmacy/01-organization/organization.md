# 組織と薬局

現在のモデル案は [組織・基盤](README.md) 以下の各文書を参照する。

本書の「法人グループ」は現在の文書の「企業グループ」、「法人」は「企業」に相当する。用語の定義は [用語・履歴と領域間の受け渡し](organization-contracts.md#用語) を参照する。活動の主体や責任については [企業・企業グループ](corporate.md) で整理している。

## 用語の候補

| 用語 | 意味の案 | 検討事項 |
| --- | --- | --- |
| 法人グループ | 複数の法人をまとめて扱う単位 | 資本関係、経営上の所属、提携の区別 |
| 法人 | 法人格を持つ組織 | 法人番号等の識別、名称・所在地の履歴 |
| 開設者 | 薬局の開設主体として扱う当事者 | 法人と個人の表現、運営主体との違い |
| 店舗 | 業務を行う拠点 | 物理的場所と事業上の店舗の同一性 |
| 許可・指定 | 店舗等に関する行政上の情報 | 対象、期間、更新・変更の扱い |

## 関係の案

- 法人のグループ所属、法人間の資本関係、FC等の契約関係を区別する。
- 店舗と開設者の関係には期間を持たせる案を検討する。
- 店舗の識別子と、許可・指定や保険薬局コードの識別子を区別する案を検討する。
- グループ所属からデータ閲覧権限を自動的に決めるかは別の判断とする。

## モデルを確かめる事例

1. グループに属さない法人が一店舗を運営する。
2. 一つのグループに複数の法人があり、それぞれが複数店舗を運営する。
3. 資本関係のない法人間で提携やFC契約を結ぶ。
4. 店舗の場所を維持したまま事業譲渡が起きる。
5. 法人の合併や店舗の移転が起きる。

これらを扱う必要性と、変更前の業務記録から当時の関係を参照する必要性を相談する。各事例の法的な手続や識別子の変化は一次資料で確認する。
