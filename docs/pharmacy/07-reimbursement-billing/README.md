# 算定・会計・請求

窓口会計・請求は対象に含める。企業の財務会計は外部に任せる。

[ドメイン一覧](../domain-candidates.md) の算定、窓口会計、保険等の請求を整理する。

個別文書は以下の3つで構成する。在庫・物販は [別レイヤー](../08-inventory-retail/README.md) で扱う。

- [調剤報酬算定](reimbursement.md): 処方・調剤・指導実績から無状態に点数・加算・減算・摘要コメント（`TK` 選択式コメント10類型）を計算
- [窓口会計](payment.md): 算定結果と自己負担割合・公費上限・自費項目から請求額（10円未満四捨五入・減免禁止）・領収書/明細書（0円患者含む無償交付）・未収を確定
- [保険等の請求・審査支払](billing-claim.md): 月次レセプト16レコード集約・5大提出ゲート・振替分割・返戻再請求・請求前3者突合点検・増減通知フィードバック
- [インタラクティブ図解 (HTML)](diagram.html): 調剤基本料3段階・時間外基礎額・窓口会計・レセ電16レコード順序と返戻/再請求ライフサイクルの図解
