# 薬局ドメイン仕様

レセコン・電子薬歴の一体型クラウドシステムにおける薬局ドメインモデルを定義する。レセコンと電子薬歴は業務上の責務として分離し、複数アプリケーションから再利用可能なドメインモデルとして構成する。一体型システム内部では患者・処方・受付情報を直接共有し、NSIPSは外部システム連携用および他社分包機等への機器連携用として扱う。詳細は [一体型内部と外部連携の境界](external-integration.md) を参照。

法人開設・個人開設の双方を対象とし、1開設者（法人または個人）＝1テナントとしてデータを分離する。インシデント・ヒヤリハットは店舗から起票し、発生店舗の開設者が管理する。

対象範囲は薬局業務全体（組織・施設基準、マスタ参照、患者・資格、処方・調剤、服薬指導・薬歴・フォローアップ・医療安全、在宅医療、調剤報酬算定・窓口会計・保険請求、在庫・物販）とする。スタッフの資格・配属・勤務は対象に含め、給与計算・人事評価・企業の財務会計は外部システムの責務とする。
