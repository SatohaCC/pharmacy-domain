# 患者・受給資格

対象候補は [ドメイン候補一覧](../domain-candidates.md) を参照。

来局やイベントを跨いで長期維持される**患者マスタ・臨床プロファイル（頭書き）・家族情報**と、**医療保険・介護保険・公費負担医療の受給資格**を扱う。すべての処方受付・相談・フォローアップ・在宅イベントの入口となる。

- [患者](patient.md): テナント内全店舗共通の患者、レセコン共通患者番号の対応、臨床プロファイル（頭書き）、同意、家族管理、M&A等での患者マージと分離
- [保険・公費等](coverage.md): 医療保険・介護保険・公費負担医療（第1〜第4公費）の資格確認、レセ電記号・番号制約、同月内資格変更検知、調剤日時点の適用スナップショット
- [インタラクティブ図解 (HTML)](diagram.html): 患者・頭書き・家族・M&Aマージ/分離構造と、医療/介護/公費資格・レセ電レコード（`RE`/`HO`/`KO`/`SN`/`JD`/`MF`）の図解

関連: [薬局ドメイン全体関係図 (HTML)](../diagram.html)、[業務フロー](../workflow.md)、[内部と外部連携の境界](../external-integration.md)。
